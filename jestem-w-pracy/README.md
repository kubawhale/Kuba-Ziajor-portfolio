# jestem-w-pracy-
apka do zliczania godzin w pracy

**Apka:** https://kubawhale.github.io/Kuba-Ziajor-portfolio/jestem-w-pracy/

Przyciski: **Jestem w Under** → **Przerwa** / **Wracam z przerwy** → **Wychodzę z pracy**.
Podsumowanie za wybrany okres pobierzesz jako **PNG** (do wysłania) albo **CSV** (do Excela).

## Na iPhonie
1. Otwórz link w **Safari**.
2. Stuknij **Udostępnij** → **Do ekranu początkowego**.
3. Uruchamiaj apkę z ikony „Under”.

Każdy ma swoje godziny tylko na własnym telefonie, bez kont i serwera.
Co jakiś czas zrób **Ustawienia → Zapisz kopię**. Na nowym telefonie wczytasz ją przyciskiem **Wczytaj kopię**.

## Zasady liczenia
- Przerwy się nie liczą.
- Zmiana po północy liczy się do dnia, w którym się zaczęła.
